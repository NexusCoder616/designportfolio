The Wizarding Archive

A redesigned front end for my Harry Potter character management system: a quiet, editorial catalogue of witches and wizards, filterable by house.

Read the case study
Problem
A character database is easy to build and hard to enjoy. The goal was a front end that feels like a museum catalogue, not an admin table.
Process
I chose an editorial look: Playfair Display and Inter in ivory and obsidian, with no decorative color. The copy follows the same voice, so “Registry Access” replaces “Sign in”. It is built with React 19 and Vite, with login-gated routes and a house filter.
Outcome
A working full-stack archive. The React front end talks to an Express and MongoDB API, and character portraits are stored on Cloudinary.

Multimedia Compression & Streaming Analyzer

A Node.js tool that analyzes images, audio and video: compression, bitrates and streaming behavior.

Read the case study
Problem
Compression and streaming happen out of sight. The goal was to make it visible what happens to a file when it is compressed and streamed.
Process
I built an Express API that compresses images with sharp and transcodes audio and video with ffmpeg, including 360p, 720p and 1080p versions with an adaptive bitrate simulation. Range requests make audio and video seekable, SQLite keeps an analysis history, and helmet, rate limiting and path sanitization protect the server.
Outcome
A deployed tool with a live demo and a documented API for images, audio, video, jobs and analysis history.
